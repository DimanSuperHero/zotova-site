## Цель спицы
Сделать и довести до деплоя сайт для массажистки Анны Зотовой. Сайт работает как первый рабочий кейс в портфолио Дмитрия (см. `business/freelance`).

## Заказчик
- **Имя:** Анна Зотова
- **Ниша:** массаж (wellness)
- **Стиль:** уютный, тёплый, но профессиональный. Никакой эротики и двусмысленности — есть отдельный FAQ-вопрос про это.
- **Палитра:** пыльно-розовый + золото + винный.
- **Шрифты:** Cormorant (заголовки).

## Технический стек
- Vite + React + Tailwind + react-router-dom.
- Контент в `src/data.js`.
- Ассеты (видео в hero, портрет в био) в `public/assets/`.
- Запуск: `npm run dev` из `projects/zotova-site/`.

## Архитектура сайта
- 8 маршрутов: `/`, `/about`, `/techniques`, `/techniques/:slug`, `/reviews`, `/faq`, `/booking`, `/contacts`.
- 9 компонентов, страницы в `src/pages/`.
- FAQ — 8 вопросов (эротика, первый сеанс, противопоказания, сон, частота, сертификаты, что взять, перенос).
- Техники: Тёплый шёлк, Тандем, локальные.
